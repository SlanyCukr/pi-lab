**Would not ship.** Two confirmed defects in changed logic:

1. **P1 — Advertised stop can leave a worker running indefinitely.** [index.ts:422](/home/slanycukr/pi-lab/wip/bg-bash/index.ts:422), [index.ts:480](/home/slanycukr/pi-lab/wip/bg-bash/index.ts:480). After hand-off, `kill -- -<pgid>` can terminate the shell while a worker ignores SIGTERM and continues writing. The compensating SIGKILL runs only inside `finish`, but continuous output re-arms the 100 ms drain timer, preventing `finish` indefinitely. V1 killed remaining group members directly upon observing the signalled exit. **Minimal fix:** perform that group kill in the shell’s `exit` handler, before waiting for output drainage; preserve the existing escalation path for extension-initiated termination.

2. **P2 — A late wait duplicates completion and can trigger an unnecessary agent turn.** [index.ts:469](/home/slanycukr/pi-lab/wip/bg-bash/index.ts:469), [index.ts:512](/home/slanycukr/pi-lab/wip/bg-bash/index.ts:512). A main-session job finishes while the agent is busy, so its report enters `queued`. Before `agent_end`, the agent calls `pi-bg-wait bg1`, which returns the stored result immediately. The queued report remains and subsequently arrives again with `triggerTurn: true`. Checking `job.waiters` only at completion cannot prevent this ordering. **Minimal fix:** queue completion records by job identity and consume/remove an undelivered record when a wait returns its final result.

An in-memory harness executing the current source with mocked processes, filesystem and timers reproduced both paths. These were not live subprocess tests; no files were modified.

The four previous fixes are present: termination guards prevent hand-off, TTL traversal avoids nested user data, `stopAll` records a result and wakes waiters, and shell resolution precedes opening the log fd. I found no additional confirmed payload corruption or TTL-ordering defect: converting the explicit breakpoints uniformly to one hour preserves Anthropic’s [longer-before-shorter requirement](https://platform.claude.com/docs/en/build-with-claude/prompt-caching).
