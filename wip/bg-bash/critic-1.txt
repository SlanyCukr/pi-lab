1. **High — spawn failure can crash Pi** ([index.ts:138](/home/slanycukr/pi-lab/wip/bg-bash/index.ts:138), error handler at 165). A deleted working directory or missing `bash` produces no PID and schedules an asynchronous `error`. Line 138 throws before installing its listener; catching the tool rejection does not prevent Node’s unhandled-error crash. Reproduced with a nonexistent cwd: synchronous error caught, then process exited 1. **Fix:** install the error listener immediately after `spawn`, before checking `pid`.

2. **High — unsafe shared-temp creation** ([index.ts:128](/home/slanycukr/pi-lab/wip/bg-bash/index.ts:128)–131). Another user can precreate `/tmp/pi-bg-bash-<uid>` as an attacker-controlled directory. Recursive `mkdir` neither validates ownership nor repairs permissions; `"w"` follows symlinks and preserves existing-file permissions. Prepopulated log names can expose secrets or redirect truncation into victim-owned files. **Fix:** use a fresh private `mkdtempSync` directory and exclusive `"wx"` log creation.

3. **High — shutdown can leave jobs running** ([index.ts:93](/home/slanycukr/pi-lab/wip/bg-bash/index.ts:93)–100, 120–121). A command ignoring SIGTERM survives shutdown: escalation is unreferenced, the map is cleared, and the process-exit fallback therefore sees nothing. If Pi exits before two seconds, SIGKILL never happens. **Fix:** retain stopping jobs for the exit fallback; await escalation during shutdown or kill synchronously.

4. **High — stale escalation can kill an unrelated process group** ([index.ts:98](/home/slanycukr/pi-lab/wip/bg-bash/index.ts:98), 146). After SIGTERM succeeds, the untracked SIGKILL timer survives `finish`. If that group disappears and its numeric ID is reused within the grace interval, another job receives SIGKILL. **Fix:** remove delayed numeric-PGID escalation; immediate group SIGKILL is the smallest change. Preserving graceful termination requires supervision that retains group identity.

5. **Medium — foreground execution discards stock settings** ([index.ts:194](/home/slanycukr/pi-lab/wip/bg-bash/index.ts:194)). Recreating the definition without options loses configured `shellPath` and `shellCommandPrefix`, which [Pi v0.85 supplies explicitly](https://github.com/earendil-works/pi/blob/v0.85.0/packages/coding-agent/src/core/agent-session.ts#L2587). A command requiring the configured environment prefix now fails or uses the wrong environment, including in sub-agents. **Fix:** delegate to the configured definition or pass the same resolved options.

6. **Medium — scheduled delivery survives shutdown** ([index.ts:109](/home/slanycukr/pi-lab/wip/bg-bash/index.ts:109)–110). Once spliced, a batch escapes `queued.length = 0`. Shutdown before the immediate runs still calls `send`, potentially waking a closing session. **Fix:** retain and cancel the immediate on shutdown, and check shutdown/session generation inside its callback.
